ClawRoute

Open-source LLM cost router · 80+ stars, 13 forks Feb 2026
  • A local HTTP proxy that intercepts LLM requests, classifies task complexity with sub-5ms local heuristics, and routes simple work to cheap models and hard work to frontier models — 60–90% cost reduction, with automatic escalation on failure.
  • Works with any OpenAI-compatible client. Ships a real-time savings dashboard, per-request SQLite cost tracking, and a dry-run mode.
  • Reached 80+ stars organically within weeks of launch.

TypeScript · Node.js · Hono · SQLite · OpenAI / Anthropic / Gemini / DeepSeek APIs

FinalWhistle

TypeScript · Solana · TxODDS TxLINE
